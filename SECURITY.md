# Security Policy

## Scope
The Vault is a local-first Android app. Security issues can include, but are not limited to:
- Encryption or key management weaknesses
- Authentication or lockout bypasses
- Data leakage (database, files, backups, logs)
- Backup or restore integrity problems
- Privilege escalation or sandbox escape

## Reporting a Vulnerability
Please do not open public issues for security-sensitive reports.

Use one of these options:
- GitHub Security Advisories for this repository (preferred)
- If advisories are not available, open an issue with minimal details and ask for a private channel

Include:
- A clear description of the issue and impact
- Steps to reproduce
- Affected versions or commit hashes
- Any proof-of-concept code if available

We will acknowledge receipt and follow up as quickly as possible.

## Security Tips for Users
- Use a strong PIN and enable biometric unlock where available.
- Keep your device OS up to date.
- Store backup recovery phrases securely and offline.
